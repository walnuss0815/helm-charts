Get the application URL by running these commands:
{{- if .Values.server.httpRoute.enabled }}
  {{- if .Values.server.httpRoute.hostnames }}
    export APP_HOSTNAME={{ .Values.server.httpRoute.hostnames | first }}
  {{- end }}
  echo "Visit http://$APP_HOSTNAME to use your application"
{{- else if .Values.server.ingress.enabled }}
  {{- range $host := .Values.server.ingress.hosts }}
    http{{ if $.Values.server.ingress.tls }}s{{ end }}://{{ $host.host }}
  {{- end }}
{{- else if contains "NodePort" .Values.server.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "immich.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.server.service.type }}
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "immich.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.server.service.port }}
{{- else if contains "ClusterIP" .Values.server.service.type }}
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "immich.name" . }},app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  echo "Visit http://127.0.0.1:8080 to use your application"
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8080:$CONTAINER_PORT
{{- end }}

On first run, open the web UI and create your admin account (there are no default
credentials).

Notes:
{{- if and .Values.postgres.enabled (not (include "immich.databasePasswordProvided" .)) }}
- The database password was not provided. CloudNativePG generated a random one,
  stored in the Secret `{{ include "immich.fullname" . }}-postgresql-app`.
{{- end }}
- The database password is sourced from `postgres.password` (inline value, existing
  secret or the CNPG-generated `<fullname>-postgresql-app` Secret).
- Set `jwtSecret` (inline value or existing secret) to keep sessions valid across
  workload restarts.
- To configure Immich features that are not exposed as dedicated values (e.g.
  `oauth`, `ffmpeg`, `notifications.smtp`, `theme`), provide the config as a YAML
  map in `config.content`. Sensitive values must be written as
  `${UPPER_SNAKE_CASE}` placeholders and supplied under `config.env` (a plain
  `value`, an existing `secretKeyRef` or a `configMapRef`). The base config
  (without secrets) lives in a ConfigMap; an init step substitutes the values
  into the file the server reads via `IMMICH_CONFIG_FILE`.
- To enable Prometheus metrics set `monitoring.enabled: true`. This sets
  `IMMICH_TELEMETRY_INCLUDE=all` and exposes the metrics ports. Set
  `monitoring.serviceMonitors.enabled: true` to also create ServiceMonitors
  (requires a Prometheus Operator with the CRDs installed).
- Set `redis.host` when `valkey.enabled` is `false`.
- For hardware accelerated machine learning set `machineLearning.image.tagSuffix`
  (e.g. `-cuda`) and provide the required device resources via `machineLearning.resources`,
  `machineLearning.nodeSelector` and `machineLearning.tolerations`.
- Set `upload-optimizer.enabled: true` to deploy the bundled immich-upload-optimizer
  proxy, which losslessly recompresses images/transcodes videos before they reach
  Immich. It is not wired into `server.ingress`/`server.httpRoute` automatically:
  expose it externally via `upload-optimizer.ingress`/`upload-optimizer.httpRoute`
  instead so uploads are actually routed through it.
